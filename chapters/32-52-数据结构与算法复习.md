## 第 32 章 数据结构概述

**一句话记忆**：数据结构 = 数据元素 + 元素之间的关系；程序 = 数据结构 + 算法。

### 逻辑结构（和语言无关）

| 结构 | 关系 | 例子 |
|---|---|---|
| 集合 | 同属一组，没有别的联系 | 一堆标签 |
| 线性 | 一对一，有头有尾 | 数组、链表、栈、队列 |
| 树 | 一对多，有层次 | 文件目录、家谱 |
| 图 | 多对多 | 地图、社交网络 |

### 存储结构（内存里怎么放）

- **顺序存储**：逻辑相邻，物理也相邻（数组）。
- **链式存储**：逻辑相邻，物理可以分散（链表结点 + 指针）。
- **索引存储**：额外维护一张目录表。
- **散列存储**：用关键字算出地址（哈希表）。

### 复杂度直觉

| 复杂度 | 数据量 100 万时大概 |
|---|---|
| O(1) | 1 次 |
| O(log n) | 20 次 |
| O(n) | 100 万次 |
| O(n log n) | 2000 万次 |
| O(n²) | 1 万亿次（不可接受） |

**易错点**：`O(1)` 指常数时间，不是"一次"；均摊复杂度 ≠ 最坏复杂度。

## 第 33 章 动态数组

**一句话记忆**：一块连续内存 + `length`（用了多少）+ `capacity`（能装多少），满了就翻倍扩容。

**代码**：[33-动态数组/dynamic_array.c](33-动态数组/dynamic_array.c)

```c
typedef struct {
    int *data;
    size_t length;      // 元素个数
    size_t capacity;    // 容量
} Vector;

bool push(Vector *v, int value) {
    if (v->length == v->capacity) {
        size_t new_cap = v->capacity ? v->capacity * 2 : 1;
        int *grown = realloc(v->data, new_cap * sizeof *grown);
        if (grown == NULL) return false;   // 失败时保留原指针
        v->data = grown;
        v->capacity = new_cap;
    }
    v->data[v->length++] = value;
    return true;
}
```

### 复杂度

| 操作 | 复杂度 |
|---|---|
| 按下标访问 | O(1) |
| 尾部插入（均摊） | O(1) |
| 中间插入 / 删除 | O(n) |
| 查找 | O(n) |

**易错点**：

- `realloc` 失败会返回 NULL，**不能直接覆盖原指针**，否则内存泄漏。
- 扩容通常按 2 倍增长，均摊到每次插入才是 O(1)。
- 删除中间元素后要 `memmove`，别留下"空洞"。

**应用**：几乎所有语言的 `vector` / `ArrayList`、可变长度缓冲区。

## 第 34 章 链表

**一句话记忆**：每个结点存数据和下一个结点的地址，物理上不用连续。

**代码**：[34-链表/linked_list.c](34-链表/linked_list.c)

```c
typedef struct Node {
    int data;
    struct Node *next;
} Node;

// 在 prev 后面插入
Node *node = malloc(sizeof *node);
node->data = value;
node->next = prev->next;
prev->next = node;
```

用二级指针删除，头结点和中间结点一套代码：

```c
Node **pp = &list->header;
while (*pp != NULL && (*pp)->data != key) {
    pp = &(*pp)->next;
}
if (*pp != NULL) {
    Node *doomed = *pp;
    *pp = doomed->next;
    free(doomed);
}
```

### 复杂度

| 操作 | 复杂度 |
|---|---|
| 按下标查找 | O(n) |
| 已知前驱插入 / 删除 | O(1) |
| 头插 / 头删 | O(1) |
| 遍历 | O(n) |

**易错点**：

- 删除时先保存 `next` 再 `free`，否则访问已释放内存。
- 释放链表要边遍历边保存下一个结点。
- 单链表不能随机访问，别拿它当数组用。

**应用**：LRU 缓存、邻接表、内存池空闲链表。

## 第 35 章 栈

**一句话记忆**：只在一端进出，后进先出（LIFO）。

**代码**：[35-栈/stack.c](35-栈/stack.c)

```c
push: data[length++] = value;
pop:  value = data[--length];
```

### 复杂度

入栈、出栈都是 **O(1)**。

**易错点**：

- 空栈 `pop` 要直接失败，不能访问 `data[length - 1]`。
- 用数组实现时，栈顶下标是 `length - 1`，不是 `length`。

**应用**：函数调用栈、括号匹配、表达式求值、撤销操作、DFS。

## 第 36 章 队列

**一句话记忆**：队尾进、队头出，先进先出（FIFO）。

**代码**：[36-队列/queue.c](36-队列/queue.c)

```c
// 循环队列：把数组看成首尾相接的环
rear  = (rear + 1) % capacity;
front = (front + 1) % capacity;
```

- 用 `length` 记录元素个数：`length == 0` 空，`length == capacity` 满。
- 不用 `length` 时通常浪费一个格子：`front == rear` 空，`(rear + 1) % cap == front` 满。

### 复杂度

入队、出队都是 **O(1)**。

**易错点**：

- 普通数组队列会出现"假溢出"：`rear` 到末尾，前面却有空位。
- 循环队列遍历要从 `front` 开始走 `length` 步，不能从下标 0 打印。

**应用**：BFS、任务队列、生产者消费者缓冲、消息队列。

## 第 37 章 哈希表

**一句话记忆**：用哈希函数把 key 变成一个数组下标，平均 O(1) 找到；冲突就挂链。

**代码**：[37-哈希表/hash_table.c](37-哈希表/hash_table.c)

```c
#define BUCKET_COUNT 11

static size_t hash_key(int key) {
    return (size_t)((unsigned int)key % BUCKET_COUNT);  // 负数也不会得到负下标
}

static bool put(HashTable *t, int key, int value) {
    size_t i = hash_key(key);
    for (Entry *e = t->buckets[i]; e; e = e->next)
        if (e->key == key) { e->value = value; return false; }  // 更新

    Entry *e = malloc(sizeof *e);
    e->key = key; e->value = value;
    e->next = t->buckets[i];      // 头插 O(1)
    t->buckets[i] = e;
    t->size++;
    return true;
}
```

### 复杂度

| 操作 | 平均 | 最坏 |
|---|---|---|
| 查找 / 插入 / 删除 | O(1) | O(n) |

**装填因子** = 元素个数 / 桶数。超过 0.75 左右通常扩容并重新散列。

**易错点**：

- 负数取余会得到负下标，先转 `unsigned`。
- 最坏情况所有 key 撞在一个桶，退化成链表。
- 删除要同时处理头结点。

**应用**：字典、缓存、去重、符号表、数据库哈希索引。

## 第 38 章 二叉树

**一句话记忆**：每个结点最多两个孩子；遍历就是"根"放在什么时候访问。

**代码**：[38-二叉树/binary_tree.c](38-二叉树/binary_tree.c)

```c
void preorder(const TreeNode *root) {   // 根 -> 左 -> 右
    if (root == NULL) return;
    printf("%d ", root->data);
    preorder(root->left);
    preorder(root->right);
}

void inorder(const TreeNode *root) {    // 左 -> 根 -> 右
    if (root == NULL) return;
    inorder(root->left);
    printf("%d ", root->data);
    inorder(root->right);
}

void postorder(const TreeNode *root) {  // 左 -> 右 -> 根
    if (root == NULL) return;
    postorder(root->left);
    postorder(root->right);
    printf("%d ", root->data);
}
```

层序遍历用队列：

```c
queue[tail++] = root;
while (head < tail) {
    const TreeNode *node = queue[head++];
    printf("%d ", node->data);
    if (node->left)  queue[tail++] = node->left;
    if (node->right) queue[tail++] = node->right;
}
```

### 性质

- 第 i 层最多 `2^(i-1)` 个结点。
- 深度 k 的二叉树最多 `2^k - 1` 个结点。
- 遍历、结点数、高度都是 **O(n)**。

**易错点**：

- 空树要作为递归出口。
- 释放内存必须用后序：先释放孩子，再释放自己。
- 前序/中序/后序不是"访问顺序不同"，而是"根的访问时机不同"。

**应用**：表达式树、文件目录、决策树、堆、数据库索引。

## 第 39 章 二叉搜索树（BST）

**一句话记忆**：左子树全小，右子树全大；中序遍历一定有序。

**代码**：[39-二叉搜索树/bst.c](39-二叉搜索树/bst.c)

```c
TreeNode *insert(TreeNode *root, int data) {
    if (root == NULL) return create_node(data);
    if (data < root->data)      root->left  = insert(root->left, data);
    else if (data > root->data) root->right = insert(root->right, data);
    return root;   // 相等不插入
}
```

删除分三种情况：

```c
if (root->left == NULL)  { TreeNode *r = root->right; free(root); return r; }
if (root->right == NULL) { TreeNode *l = root->left;  free(root); return l; }

TreeNode *successor = find_min(root->right);  // 右子树最小值
root->data = successor->data;
root->right = bst_delete(root->right, successor->data);
```

### 复杂度

| 操作 | 平均 | 最坏（退化成链） |
|---|---|---|
| 查找 / 插入 / 删除 | O(log n) | O(n) |

**易错点**：

- 按 1、2、3、4…… 顺序插入会退化成链表。
- 删除有两个孩子的结点，要用右子树最小值（后继）替换。
- 中序有序是 BST 的核心性质，很多题靠它。

**应用**：有序集合、范围查询、`std::map` / `set` 的基础、数据库索引思想。

## 第 40 章 平衡二叉树 AVL

**一句话记忆**：BST 每次插入后检查平衡因子（左高 - 右高），不在 -1/0/1 就旋转。

**代码**：[40-平衡二叉树/avl.c](40-平衡二叉树/avl.c)

```c
static int height(const AvlNode *n) { return n ? n->height : 0; }
static int balance_factor(const AvlNode *n) {
    return height(n->left) - height(n->right);
}
```

四种旋转：

```c
// LL：右旋
if (bf > 1 && data < node->left->data)
    return rotate_right(node);

// RR：左旋
if (bf < -1 && data > node->right->data)
    return rotate_left(node);

// LR：先左旋左孩子，再右旋自己
if (bf > 1 && data > node->left->data) {
    node->left = rotate_left(node->left);
    return rotate_right(node);
}

// RL：先右旋右孩子，再左旋自己
if (bf < -1 && data < node->right->data) {
    node->right = rotate_right(node->right);
    return rotate_left(node);
}
```

旋转只改几个指针，一次 O(1)。

### 复杂度

查找、插入、删除都是 **O(log n)**，树高始终保持 O(log n)。

**易错点**：

- 旋转后要先更新低层结点高度，再更新高层。
- 判断 LL/LR 要看"新结点插在左孩子的哪一边"，不是只看高度。
- AVL 删除比插入复杂，很多教材只要求掌握插入。

**应用**：内存中的有序映射、需要稳定 O(log n) 的索引结构。

## 第 41 章 堆与优先队列

**一句话记忆**：完全二叉树用数组存，大根堆的堆顶就是最大值；插入上浮，删除下沉。

**代码**：[41-堆与优先队列/heap.c](41-堆与优先队列/heap.c)

下标关系（从 0 开始）：

```
父结点 = (i - 1) / 2
左孩子 = 2 * i + 1
右孩子 = 2 * i + 2
```

```c
bool heap_push(MaxHeap *h, int value) {
    size_t i = h->size++;
    h->data[i] = value;
    while (i > 0) {
        size_t parent = (i - 1) / 2;
        if (h->data[parent] >= h->data[i]) break;
        swap(&h->data[parent], &h->data[i]);
        i = parent;
    }
    return true;
}

bool heap_pop(MaxHeap *h, int *value) {
    *value = h->data[0];
    h->data[0] = h->data[--h->size];
    sift_down(h, 0);
    return true;
}
```

建堆从最后一个非叶子结点（`n/2 - 1`）开始下沉，总复杂度 **O(n)**。

### 复杂度

| 操作 | 复杂度 |
|---|---|
| 看堆顶 | O(1) |
| 插入 | O(log n) |
| 删除堆顶 | O(log n) |
| 建堆 | O(n) |

**易错点**：

- 堆只保证最值在堆顶，不保证整体有序。
- 出堆时先把最后一个元素搬到堆顶，再下沉。
- 大根堆找最大值 O(1)，找最小值要 O(n)。

**应用**：优先队列、Top K、任务调度、Dijkstra 优化、定时器。

## 第 42 章 排序

**代码**：[42-排序/sorting.c](42-排序/sorting.c)

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 |
|---|---|---|---|---|---|
| 冒泡 | O(n) | O(n²) | O(n²) | O(1) | ✅ |
| 选择 | O(n²) | O(n²) | O(n²) | O(1) | ❌ |
| 插入 | O(n) | O(n²) | O(n²) | O(1) | ✅ |
| 归并 | O(n log n) | O(n log n) | O(n log n) | O(n) | ✅ |
| 快速 | O(n log n) | O(n log n) | O(n²) | O(log n) | ❌ |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | ❌ |

**快速排序核心**：

```c
size_t partition(int *a, size_t low, size_t high) {
    int pivot = a[high];
    size_t i = low;
    for (size_t j = low; j < high; j++) {
        if (a[j] < pivot) swap(&a[i++], &a[j]);
    }
    swap(&a[i], &a[high]);
    return i;
}
```

**归并排序核心**：

```c
while (i < mid && j < right)
    temp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
// 用 <= 才能保持稳定
```

**易错点**：

- 快排已有序 + 总选最后一个当基准 → O(n²)；工程上用随机基准或三数取中。
- 归并需要 O(n) 额外空间。
- 稳定性：值相等的元素排序前后相对顺序不变。
- 小数组用插入排序，大数组用快排/归并，是常见工程组合。

**应用**：排行榜、数据分析、数据库排序、`qsort`。

## 第 43 章 查找

**代码**：[43-查找/search.c](43-查找/search.c)

```c
int binary_search(const int *a, size_t n, int key) {
    size_t low = 0, high = n;          // 区间 [low, high)
    while (low < high) {
        size_t mid = low + (high - low) / 2;   // 防溢出
        if (a[mid] == key) return (int)mid;
        if (a[mid] < key) low = mid + 1;
        else              high = mid;
    }
    return -1;
}
```

`lower_bound`：第一个 `>= key` 的位置：

```c
if (a[mid] < key) low = mid + 1;
else              high = mid;
return low;
```

### 复杂度

| 算法 | 前提 | 复杂度 |
|---|---|---|
| 线性查找 | 无 | O(n) |
| 二分查找 | **数组有序** | O(log n) |

**易错点**：

- `(low + high) / 2` 可能整数溢出，用 `low + (high - low) / 2`。
- 二分必须有序；无序数组先排序再二分，要看排序成本是否值得。
- 区间开闭要统一，`[low, high)` 是最不容易出错的写法。

**应用**：字典、数据库索引、`git bisect`、猜数字。

## 第 44 章 图

**一句话记忆**：多对多关系；邻接矩阵查边快但费空间，邻接表省空间适合稀疏图。

**代码**：[44-图/graph.c](44-图/graph.c)

### 两种存储

| 存储 | 空间 | 查两点是否相连 | 适合 |
|---|---|---|---|
| 邻接矩阵 | O(V²) | O(1) | 稠密图 |
| 邻接表 | O(V + E) | O(度数) | 稀疏图 |

### BFS（队列）

```c
visited[start] = true;
dist[start] = 0;
queue[tail++] = start;

while (head < tail) {
    int v = queue[head++];
    for (int w = 0; w < n; w++) {
        if (matrix[v][w] && !visited[w]) {
            visited[w] = true;
            dist[w] = dist[v] + 1;   // 无权图第一次到达就是最短
            queue[tail++] = w;
        }
    }
}
```

### DFS（递归）

```c
void dfs_visit(int v, bool *visited) {
    visited[v] = true;
    for (int w = 0; w < n; w++)
        if (matrix[v][w] && !visited[w])
            dfs_visit(w, visited);
}
```

### 复杂度

- 邻接矩阵：BFS/DFS 都是 O(V²)。
- 邻接表：BFS/DFS 都是 O(V + E)。

**易错点**：

- 无向图加边要两个方向都记。
- 遍历前 `visited` 必须清零。
- 连通分量 = 对每个未访问点做一次 BFS/DFS。

**应用**：社交网络、地图导航、网页链接、任务依赖、连通性检查。

## 第 45 章 最短路径 Dijkstra

**一句话记忆**：每次选当前距离最小的未确定点，用它去"松弛"邻居；边权不能为负。

**代码**：[45-最短路径/dijkstra.c](45-最短路径/dijkstra.c)

```c
dist[start] = 0;

for (int step = 0; step < n; step++) {
    int u = -1;
    for (int i = 0; i < n; i++)
        if (!visited[i] && (u == -1 || dist[i] < dist[u]))
            u = i;
    if (u == -1 || dist[u] == INF) break;
    visited[u] = true;

    for (int v = 0; v < n; v++) {
        if (matrix[u][v] == 0) continue;
        int candidate = dist[u] + matrix[u][v];
        if (candidate < dist[v]) {
            dist[v] = candidate;
            prev[v] = u;              // 记录路径
        }
    }
}
```

### 复杂度

| 实现 | 复杂度 | 适合 |
|---|---|---|
| 朴素（每次线性找最小） | O(V²) | 稠密图 |
| 优先队列优化 | O((V + E) log V) | 稀疏图 |

**易错点**：

- **负权边不能用** Dijkstra，要用 Bellman-Ford。
- 贪心成立的原因：边权非负，后面再绕只会更大。
- 路径还原靠 `prev[]`，从终点往回走再倒序。

**应用**：地图导航、网络路由、游戏寻路、物流调度。

## 第 46 章 最小生成树

**一句话记忆**：用 V-1 条边把所有点连通且不成环，总权最小。

**代码**：[46-最小生成树/mst.c](46-最小生成树/mst.c)

### Prim（加点法）

```c
key[start] = 0;
for (int step = 0; step < n; step++) {
    int u = -1;
    for (int i = 0; i < n; i++)
        if (!in_mst[i] && (u == -1 || key[i] < key[u])) u = i;
    in_mst[u] = true;

    for (int v = 0; v < n; v++)
        if (matrix[u][v] && !in_mst[v] && matrix[u][v] < key[v]) {
            key[v] = matrix[u][v];     // 注意：存的是边权，不是路径长度
            parent[v] = u;
        }
}
```

### Kruskal（加边法 + 并查集）

```c
qsort(edges, edge_count, sizeof *edges, cmp_by_weight);

for (int i = 0; i < edge_count && used < n - 1; i++) {
    if (uf_union(&uf, edges[i].u, edges[i].v)) {
        total += edges[i].weight;
        used++;
    }
    // 已经连通就跳过，避免成环
}
```

### 复杂度

| 算法 | 复杂度 | 适合 |
|---|---|---|
| Prim（朴素） | O(V²) | 稠密图 |
| Kruskal | O(E log E) | 稀疏图 |

**易错点**：

- Prim 的 `key[v]` 是"到树的最短边权"，不是"起点到 v 的路径长度"。
- Kruskal 必须先排序，再用并查集判环。
- 图不连通时不存在生成树。

**应用**：网络布线、修路、电网、水管、聚类。

## 第 47 章 动态规划

**一句话记忆**：把大问题拆成会重复计算的小问题，定义状态、写转移、定边界、按顺序填表。

**代码**：[47-动态规划/dp.c](47-动态规划/dp.c)

### 设计 DP 的四步

1. **状态**：`dp[i]` 或 `dp[i][j]` 表示什么？
2. **转移**：`dp[i]` 从哪些更小的状态来？
3. **边界**：`dp[0]` 等初始值。
4. **顺序**：保证用到的值已经算好。

### 0-1 背包（一维滚动数组）

```c
for (int i = 0; i < n; i++) {
    for (int c = capacity; c >= weights[i]; c--) {   // 必须倒序！
        int take = dp[c - weights[i]] + values[i];
        if (take > dp[c]) dp[c] = take;
    }
}
```

倒序是为了保证每件物品只用一次；正序会变成完全背包。

### 最长上升子序列

```c
for (int i = 0; i < n; i++) {
    dp[i] = 1;
    for (int j = 0; j < i; j++)
        if (a[j] < a[i] && dp[j] + 1 > dp[i])
            dp[i] = dp[j] + 1;
}
```

### 复杂度

视状态数 × 转移代价而定。背包 O(n × capacity)，LIS 朴素 O(n²)。

**易错点**：

- 状态定义不清，转移一定写错。
- 背包一维必须倒序。
- 自顶向下记忆化 vs 自底向上递推，选一个熟悉的即可。

**应用**：背包、编辑距离、股票买卖、路径计数、资源分配。

## 第 48 章 字符串匹配 KMP

**一句话记忆**：失配时不回到开头，而是根据 `pi` 数组把模式串滑到"还能对上"的位置。

**代码**：[48-字符串匹配/kmp.c](48-字符串匹配/kmp.c)

```c
// pi[i] = pattern[0..i] 的最长"真前缀 == 真后缀"长度
void build_pi(const char *p, int m, int *pi) {
    pi[0] = 0;
    int k = 0;
    for (int i = 1; i < m; i++) {
        while (k > 0 && p[i] != p[k]) k = pi[k - 1];
        if (p[i] == p[k]) k++;
        pi[i] = k;
    }
}

int kmp_search(const char *text, const char *pattern, const int *pi, int *count) {
    int k = 0, first = -1, found = 0;
    for (int i = 0; text[i]; i++) {
        while (k > 0 && text[i] != pattern[k]) k = pi[k - 1];
        if (text[i] == pattern[k]) k++;
        if (k == m) {
            if (first == -1) first = i - m + 1;
            found++;
            k = pi[k - 1];      // 继续找重叠匹配
        }
    }
    *count = found;
    return first;
}
```

### 复杂度

- 朴素匹配：最坏 O(n × m)。
- KMP：预处理 O(m)，匹配 O(n)，总共 **O(n + m)**。

**易错点**：

- `pi` 数组的含义是"最长真前缀等于真后缀"，不是"最长公共前后缀"随便写。
- 匹配成功后要 `k = pi[k-1]` 才能继续找重叠。
- 字符串下标从 0 开始时，回退用 `pi[k-1]`，别越界。

**应用**：编辑器查找、DNA 序列比对、日志检索、敏感词过滤（多模式用 AC 自动机）。

## 第 49 章 字典树 Trie

**一句话记忆**：字符串按字符一层层挂到树上，公共前缀只存一份。

**代码**：[49-字典树/trie.c](49-字典树/trie.c)

```c
typedef struct TrieNode {
    struct TrieNode *children[26];
    bool is_end;          // 这里是不是某个单词的结尾
} TrieNode;

void insert(TrieNode *root, const char *word) {
    TrieNode *node = root;
    for (const char *p = word; *p; p++) {
        int i = *p - 'a';
        if (node->children[i] == NULL)
            node->children[i] = calloc(1, sizeof(TrieNode));
        node = node->children[i];
    }
    node->is_end = true;
}
```

### 复杂度

插入、查找、查前缀都是 **O(m)**，m 是字符串长度，和单词总数无关。

**易错点**：

- 查前缀为真，不代表单词存在；还要看 `is_end`。
- 每个结点 26 个指针，内存开销大，可用哈希表或压缩字典树优化。
- 删除单词要谨慎处理共享前缀，别把别的单词也删了。

**应用**：输入法自动补全、拼写检查、IP 路由表、单词游戏。

## 第 50 章 回溯

**一句话记忆**：深度优先搜索 + 撤销选择；走不通就退回上一个路口。

**代码**：[50-回溯/backtracking.c](50-回溯/backtracking.c)

### 通用模板

```c
void backtrack(状态) {
    if (到达终点) {
        记录答案;
        return;
    }
    for (每个候选选择) {
        做选择;          // 修改状态
        backtrack(下一层);
        撤销选择;        // 恢复状态，关键！
    }
}
```

### 全排列

```c
for (int i = start; i < n; i++) {
    swap(&a[start], &a[i]);
    permute(a, start + 1, n);
    swap(&a[start], &a[i]);   // 撤销
}
```

### 八皇后剪枝

```c
if (cols[col] || diag1[row + col] || diag2[row - col + n - 1])
    continue;                 // 这个位置会被攻击，直接跳过
```

### 复杂度

通常是指数级：全排列 O(n!)，子集 O(2^n)。剪枝能大幅减少搜索量。

**易错点**：

- 忘记撤销选择 → 后面的分支看到被污染的状态。
- 剪枝条件写错会漏解。
- 回溯 ≠ DP：DP 让每个小问题只算一次，回溯枚举所有路径。

**应用**：八皇后、数独、走迷宫、组合/子集、正则匹配。

## 第 51 章 贪心

**一句话记忆**：每一步都选当前看起来最好的，不回头；只有满足贪心选择性质时才是全局最优。

**代码**：[51-贪心/greedy.c](51-贪心/greedy.c)

### 活动选择

```c
qsort(activities, n, sizeof *activities, cmp_by_end);   // 按结束时间排序

int count = 0, last_end = -1;
for (int i = 0; i < n; i++) {
    if (activities[i].start >= last_end) {
        count++;
        last_end = activities[i].end;
    }
}
```

### 分数背包

按单位重量价值从高到低排序，能装整件就装整件，最后一件切开。

### 贪心的反例

硬币 `{1, 3, 4}`，找零 6：贪心拿 `4 + 1 + 1` 共 3 枚，最优是 `3 + 3` 共 2 枚。

**复杂度**：通常瓶颈在排序，O(n log n)。

**易错点**：

- 贪心不保证全局最优，必须能证明或举反例。
- 0-1 背包不能贪心，要用动态规划。
- 分数背包可以贪心，因为物品可以切分。

**应用**：活动安排、霍夫曼编码、Prim/Kruskal、Dijkstra、任务调度。

## 第 52 章 并查集

**一句话记忆**：每个元素指向父亲，根指向自己；查根 + 合并，路径压缩后接近 O(1)。

**代码**：[52-并查集/union_find.c](52-并查集/union_find.c)

```c
int uf_find(UnionFind *uf, int x) {
    if (uf->parent[x] != x)
        uf->parent[x] = uf_find(uf, uf->parent[x]);   // 路径压缩
    return uf->parent[x];
}

bool uf_union(UnionFind *uf, int a, int b) {
    int ra = uf_find(uf, a), rb = uf_find(uf, b);
    if (ra == rb) return false;

    if (uf->rank[ra] < uf->rank[rb]) { int t = ra; ra = rb; rb = t; }
    uf->parent[rb] = ra;                              // 按秩合并
    if (uf->rank[ra] == uf->rank[rb]) uf->rank[ra]++;
    uf->count--;
    return true;
}
```

### 复杂度

单次操作平均接近 **O(1)**（严格说是反阿克曼函数 α(n)，实际不超过 4）。

**易错点**：

- 只做路径压缩或只做按秩合并，复杂度都不是最优。
- 合并前必须先 `find` 到根，不能直接改 `parent[a]`。
- 并查集只能合并，不能拆分。

**应用**：连通性、朋友圈/账户合并、Kruskal、图片连通区域、判断环。

## 附二：易错点清单

1. `realloc` 失败时不要覆盖原指针。
2. 链表删除先保存 `next`，再 `free`。
3. 空栈 `pop`、空队列 `dequeue` 要返回失败。
4. 循环队列遍历从 `front` 开始走 `length` 步。
5. 哈希表负数 key 先转 `unsigned` 再取余。
6. 树的后序释放：先孩子，后自己。
7. BST 删除两个孩子的结点，用右子树最小值替换。
8. AVL 旋转后先更新低层高度。
9. 堆出堆时先把最后一个元素搬到堆顶再下沉。
10. 二分查找 `mid = low + (high - low) / 2` 防溢出。
11. 快排最坏 O(n²)，工程上随机化基准。
12. 归并用 `<=` 才稳定。
13. 无权图 BFS 第一次到达就是最短路径。
14. Dijkstra 不能处理负权边。
15. Prim 的 `key` 存边权，不是路径长度。
16. 0-1 背包一维数组必须倒序遍历容量。
17. KMP 匹配成功后 `k = pi[k-1]` 继续找重叠。
18. Trie 查前缀为真不代表单词存在，还要看 `is_end`。
19. 回溯一定要撤销选择。
20. 贪心不保证全局最优，先想反例。
