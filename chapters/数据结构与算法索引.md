## 建议学习顺序

1. **线性结构**：32 → 33 → 34 → 35 → 36
2. **哈希**：37
3. **树**：38 → 39 → 40 → 41
4. **排序与查找**：42 → 43
5. **图**：44 → 45 → 46（配合 52 并查集）
6. **算法思想**：47 动态规划 → 50 回溯 → 51 贪心
7. **字符串**：48 → 49

每一章都建议按这个节奏：

1. 先看顶部注释，弄懂它解决什么问题；
2. 关掉代码，自己写一遍核心函数；
3. 跑示例输出，对照注释理解每一步；
4. 再回来看实现，比较哪里写得更好。

## 编译运行

每个文件都是独立程序，可以单独编译：

```bash
clang -Wall -Wextra -O2 "chapters/37-哈希表/hash_table.c" -o /tmp/hash_table
/tmp/hash_table
```

建议加上内存检查，尤其是链表、树、哈希表这些用 `malloc/free` 的章节：

```bash
clang -Wall -Wextra -g -fsanitize=address,undefined \
      "chapters/39-二叉搜索树/bst.c" -o /tmp/bst
/tmp/bst
```

用 VS Code 的话，打开某个 `.c` 文件后按 `Cmd+Shift+B` 就会用现有任务编译到同目录。

## 复杂度速查

| 数据结构 | 查找 | 插入 | 删除 | 备注 |
|---|---|---|---|---|
| 数组 | O(n) | O(n) | O(n) | 随机访问 O(1) |
| 链表 | O(n) | O(1)（已知位置） | O(1)（已知前驱） | 不支持随机访问 |
| 栈 / 队列 | — | O(1) | O(1) | 只能在一端/两端操作 |
| 哈希表 | O(1) 平均 | O(1) 平均 | O(1) 平均 | 最坏 O(n) |
| 二叉搜索树 | O(log n) 平均 | O(log n) 平均 | O(log n) 平均 | 可能退化成 O(n) |
| AVL 树 | O(log n) | O(log n) | O(log n) | 严格平衡 |
| 堆 | O(1) 看堆顶 | O(log n) | O(log n) | 只保证最值 |
| 并查集 | 近似 O(1) | 近似 O(1) | — | 只支持合并和查询 |

## 关于代码来源

实现思路参考了这些高质量仓库的常见做法：

- [TheAlgorithms/C](https://github.com/TheAlgorithms/C) —— 算法覆盖面最全，适合对照查阅
- [attractivechaos/klib](https://github.com/attractivechaos/klib) —— 工业级单文件 C 工具库，哈希表和动态数组的写法非常值得精读
- [srdja/Collections-C](https://github.com/srdja/Collections-C) —— 模块化数据结构库，适合学习接口设计

这里的代码是重新编写的教学版本，重点在注释和可读性，不追求生产级性能。
