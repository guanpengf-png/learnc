# 地牢探险：数据结构与算法学习版

这是一个纯终端、单文件 C11 Roguelike 教学项目。随机地牢、回合制攻击、怪物、药水背包、商店、日志搜索和排行榜可以直接试玩；`?` 会运行一些不影响战斗状态的算法小演示。

代码集中在 [`main.c`](main.c)，并按 32–52 章在相关函数旁标注章节号。这样初学时可以先顺着完整游戏读，再跳到对应数据结构。Makefile 不依赖第三方库。

## 编译和运行

在本目录执行：

```sh
make
./dungeon
```

或直接编译：

```sh
cc -std=c11 -Wall -Wextra -Wpedantic -O2 main.c -o dungeon
```

需要能显示 UTF-8 的终端。地图使用 `#` 表示墙、`.` 表示地面、`@` 表示玩家、`g` 表示怪物。方向按 WASD 输入，每次输入一行。

## 操作

| 按键 | 功能 |
|---|---|
| `w` `a` `s` `d` | 移动；撞到怪物时攻击 |
| `b` | 查看背包 |
| `u` | 使用治疗药水 |
| `t` | 打开商店并购买 |
| `h` | 用 Dijkstra 向右下方房间自动走一步 |
| `l` | 输入关键字，用 KMP 搜索消息日志 |
| `?` | 查看 BFS、回溯、背包 DP、LIS、编辑距离和贪心找零示范 |
| `n` | 进入下一层，恢复生命并生成新地图 |
| `q` | 结束本次探险并记录分数 |

在 `he` 开头的输入后会显示 Trie 命令补全示例。效果链表示例会在战斗中偶尔触发中毒；每个游戏回合，毒效果造成伤害并递减剩余回合。

## 一局游戏如何运行

程序先初始化物品哈希索引、命令 Trie 和随机数，再创建第一层地图。主循环依次执行：绘制状态、读取一个命令、处理移动/战斗/菜单、结算持续效果和怪物袭击。玩家生命归零或输入退出后，程序把本次分数加入进程内的 AVL 排行树、打印日志并释放动态分配的背包和效果链。

地图有 8 个房间，中心点按 4×2 排列。生成器建立房间对之间的候选连线，用并查集合并分量，只有跨分量的边才挖走廊，最终所有房间连通且不需要连通环路。随机边序是为了生成变化地图；它是 Kruskal 的“按边顺序尝试 + 并查集判环”教学演示，**没有按真实几何距离排序，因此不保证走廊总长度最短**。房间布局固定、地图走廊随机，怪物随机出现在房间里。

## 重点算法讲解

### 动态数组和链表的取舍

背包需要按下标展示和删除，因此用连续数组。插入新物品时若满了就把容量翻倍，避免每次插入都重新申请；均摊到多次追加成本为 O(1)。状态效果会不断从头插入，也会在任意位置过期删除，所以单链表可以 O(1) 头插；遍历删除用二级指针保存“当前指针所在的位置”，删除头节点不需要额外分支。

### BFS、DFS 和 Dijkstra

BFS 用先进先出队列扩展节点，适用于每条边代价相同的最少步数问题。DFS 用栈深入探索，适合连通检查和回溯。Dijkstra 处理非负边权：从小根堆取出当前距离最小的格子，再尝试松弛相邻格子。泥沼会把步进代价从 1 增至 5；`prev[y][x]` 保存前驱，自动寻路从目标倒推到玩家附近，移动一步后下个回合重算。

### Kruskal 与并查集

每条边按权重从小到大尝试，若两个端点当前属于不同集合，就选这条边并合并集合；同属一个集合就会形成环，跳过。经典 Kruskal 必须先按权重排序。本教学版随机打乱边来保持地图变化，因此不保证全局最小权重，代码注释明确了这一点。并查集用路径压缩减少树高，用按秩合并避免把树挂成链。

### AVL 排行榜

排行榜的键是本次分数。AVL 节点保存子树高度，插入后计算平衡因子 `height(left)-height(right)`。绝对值超过 1 时做一次或两次旋转。旋转只改局部指针，并按“先更新低层，再更新高层”的顺序重算高度。中序逆序遍历得到从高到低的名次。此排行榜仅在当前运行期间保留，不写入磁盘。

### DP 的三种状态设计

- 背包：`dp[c]` 表示容量不超过 `c` 时可取得的最大价值。物品循环内容量倒序，防止本轮刚放入的物品被重复使用。
- LIS：`dp[i]` 表示以第 `i` 个升级路线数值结尾的最长严格递增子序列长度。
- 编辑距离：`dp[i][j]` 表示把字符串前缀 `a[0..i)` 变成 `b[0..j)` 的最少插入、删除、替换次数。

## 代码范围和扩展练习

这是学习用小型原型，不是完整商业 Roguelike：房间位置固定、没有存档、装备属性暂未进入伤害公式、商店 BST 为演示用途且不会在每次购物后释放临时节点；排行榜不持久化；怪物行为和战斗规则保持简单。可以把这些作为练习：实现真正随机 BSP 分房、按几何距离排序的 Kruskal、商店 BST 删除与释放、保存 AVL 排名、为背包添加重量上限、给怪物实现完整的 Dijkstra 追踪，以及把单文件拆成每章一个 `.c/.h` 模块。

建议学习顺序：先编译游玩，再读 `main` 和状态结构；接着读背包与效果链；然后地图生成（图、栈、并查集）、BFS/Dijkstra；最后读 AVL、DP 和字符串算法。阅读时试着先遮住实现，自己写出函数，再用 `?` 和游戏操作观察结果。
