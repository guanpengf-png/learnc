# 通讯录命令行（链表）

## 运行

```bash
cd day7/contacts
make
./contacts
```

数据文件：`contacts.txt`（姓名、电话请勿含空格）。

## 功能

| 选项 | 作用 |
|------|------|
| 1 | 头插添加 |
| 2 | 按姓名有序插入 |
| 3 | 按电话 / 姓名删除 |
| 4 | 按名字搜索（子串，不区分大小写） |
| 5 | 显示全部 |
| 6 | 按姓名归并排序 |
| 7 / 8 | 保存 / 加载 |
| 0 | 退出并保存 |

## 练习点

- `Contact` 结构体 + `next`
- 头插 / 有序插入 / 删除（`Contact **head`）
- `strstr` + 小写转换做名字模糊查找
- 快慢指针拆链表 + 归并排序（只改指针，不开数组）
